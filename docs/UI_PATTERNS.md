# 공유 UI 패턴 — 2026-11-25

Phase 0의 중립 배경/흰 카드/파랑 강조를 유지한다. 공통 토큰은 globals.css의 page #f5f6f8, surface #fff, ink #202735, accent #285bd4, line #e0e4ea. 카드 반경 12px, 버튼/입력 최소 44px.

Phase 1: 1200px 이상은 왼쪽 탐색(148px), 700px 이하는 하단 4개 탐색(버튼 최소 52px, safe-area 반영). 본문 하단 110px 여백. 보조 테이블 대신 모바일 줄바꿈 가능한 레코드 카드를 재사용한다.

편집은 본문 내 패널(최대 760px). 명시적 label/for, 열 때 제목에 포커스, 실패 시 필드 값 유지, 저장 중 필드·버튼 비활성. 확인 전 항목을 쓰지 않는다. 보관은 삭제와 구분하고 확인 후 수행, 보관 보기에서 복원한다. 합성/운영 미연결 상태는 모든 화면 상단에서 유지한다.

현재 레이아웃의 증거는 docs/screenshots/phase1-*에 기록한다. 실제 iPhone 검증으로 해석하지 않는다.

Phase 2: ‘과제 → 측정 계획’, ‘프로젝트 → 지표·전략’에서 같은 프로젝트 범위로 진입한다. 기존 하단 네 메뉴는 유지한다. 별도 measurement.css로 지표/계획/전략 UI를 한정하고 Claude 담당 records.css와 editors.tsx는 수정하지 않는다. 미승인 초안, 승인 버전, 측정 준비 누락을 각각 표시한다. 지표·계획 변경은 새 버전 버튼을 사용한다. 편집 중 전환은 확인 후 수행하며 취소하면 입력을 유지한다. 데이터 요청서는 복사 실패 안내와 내려받기를 함께 제공한다. 캡처는 docs/screenshots/phase2-*에 기록한다.

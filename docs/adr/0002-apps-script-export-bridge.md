# ADR 0002 — Galaxy Coach GA 임시 연결: 새 Apps Script 내보내기 + 수동 가져오기

- 상태: 제안 (2026-11-25)
- 관련 문서: v1.2 §4 (`docs/06-v1.2-spec.md`), `docs/REFERENCE_REVIEW.md`, `docs/COACH_GA_EXPORT.md`

## 배경

v1.2 §4.1은 PM.zip 백엔드가 GA4 Data API를 직접 호출하도록 정하고, Apps Script와 Sheets를 운영 의존성에서 제외한다. 지금은 이 방식이 막혀 있다.

- Google Cloud 콘솔은 MFA 때문에 접근할 수 없고, GA 사용자 관리 권한도 없다.
- 개발 미리보기는 GitHub Pages 정적 웹이라 서버가 없고, 로그인과 DB도 없다.

한편 기존 Coach Apps Script는 본인 계정의 GA 권한으로 이미 동작하고 있다.

## 결정

정식 직접 연동이 생기기 전까지 다음 **임시 수동 경로**를 둔다.

1. 기존 스크립트를 수정하거나 호출하지 않는다. 대신 `tools/apps-script/coach-ga-export`에 **새 내보내기용 스크립트**를 둔다. 이 스크립트는 `coach-ga4-1.2` 정의로 GA를 읽기 전용 조회해 `pmzip.coach-ga-export` v1 JSON을 만든다.
2. PM.zip은 파일을 받아 다음을 수행한다.
   - 스키마와 조회 정의 검증
   - 미리보기와 사용자 확인
   - 결정적 지표 계산
   - 추가만 하는 저장
3. 기존 익명 웹앱은 PM.zip에서 호출하지 않는다. 공개 노출 위험이 있고, 집계 기준도 v1.2와 다르기 때문이다.

이 경로는 운영 의존성이 아니다. v1.2의 직접 연동 목표를 대체하지 않는다.

## 결과

- 장점: 서버나 GA API 키 없이 실제 수치를 확인할 수 있다. 파일 형식과 계산 엔진은 이후 서버 직접 연동이나 Supabase 수집에서도 그대로 쓴다.
- 한계
  - PM.zip으로 가져오는 단계는 수동이다. Apps Script 쪽 파일 생성만 매일 자동이다.
  - 데이터는 그 브라우저에만 저장된다.
  - 실제 회사 수치를 넣으려면 조직 승인이 필요하다.
- 전환 조건: 서버 실행 환경과 로그인(예: Supabase Auth와 Edge Function), GA 인증(서비스 계정 또는 OAuth)이 승인·확보되는 것. 조건이 갖춰지면 같은 파일 형식으로 서버가 수집하고, 이 수동 경로는 비교 검증용으로만 남긴다.

# ADR 0002 — Galaxy Coach GA 연결: 새 Apps Script → 공유 시트 → PM.zip 자동 동기화

- 상태: 제안 (2026-11-25)
- 관련 문서: v1.2 §4 (`docs/06-v1.2-spec.md`), `docs/REFERENCE_REVIEW.md`, `docs/COACH_GA_EXPORT.md`

## 배경

v1.2 §4.1은 PM.zip 백엔드가 GA4 Data API를 직접 호출하도록 정하고, Apps Script와 Sheets를 운영 의존성에서 제외한다. 지금은 이 방식이 막혀 있다.

- Google Cloud 콘솔은 MFA 때문에 접근할 수 없고, GA 사용자 관리 권한도 없다.
- 개발 미리보기는 GitHub Pages 정적 웹이라 서버가 없고, 로그인과 DB도 없다.

한편 기존 Coach Apps Script는 본인 계정의 GA 권한으로 이미 동작하고 있다.

## 결정

정식 직접 연동이 생기기 전까지 다음 경로를 둔다. 이 경로는 사용자 결정에 따른 것이다. 기존 Coach 시트도 링크 공유로 운영 중이다.

1. 기존 스크립트는 수정하거나 호출하지 않는다. 대신 회사 계정의 **새 스프레드시트에 붙인 새 스크립트**(`tools/apps-script/coach-ga-export`)를 둔다.
2. 새 스크립트는 매일 `coach-ga4-1.2` 정의로 GA를 읽기 전용 조회한다. 결과는 같은 시트의 `pmzip_export` 탭에 조각 단위 JSON과 SHA-256으로 기록한다. 권한은 `analytics.readonly`, `spreadsheets.currentonly`다.
3. 시트는 링크 보기로 공유한다. PM.zip은 사용자가 그 브라우저에 입력한 시트 ID로 gviz CSV를 읽기 전용으로 받는다. 그다음 다음을 수행한다.
   - 무결성, 스키마, 정의 검증
   - 결정적 지표 계산
   - 추가만 하는 저장
4. 수동 파일 가져오기는 예비 경로로 남긴다.
5. 기존 익명 웹앱은 호출하지 않는다. 집계 기준이 v1.2와 다르기 때문이다.

v1.2 §4.1의 "Apps Script·Sheets를 운영 의존성에서 제외"와 다르다. 이 경로는 직접 연동이 가능해질 때까지의 **명시적 예외**다. 직접 연동 목표는 유지한다.

## 결과

- 장점: 서버나 GA API 키 없이 실제 수치를 확인할 수 있다. 파일 형식과 계산 엔진은 이후 서버 직접 연동이나 Supabase 수집에서도 그대로 쓴다.
- 한계
  - 링크를 아는 사람은 누구나 집계 수치를 볼 수 있다. 개인정보는 넣지 않는다.
  - 가져온 기간은 각 브라우저에 저장된다. 다른 기기는 같은 시트를 연결해 동기화한다.
  - 과제와 원문 기록은 여전히 브라우저에만 저장된다.
  - 시트를 읽을 수 있는지는 Google의 공개 gviz 응답에 달려 있다.
- 전환 조건: 서버 실행 환경과 로그인(예: Supabase Auth와 Edge Function), GA 인증(서비스 계정 또는 OAuth)이 승인·확보되는 것. 조건이 갖춰지면 같은 파일 형식으로 서버가 수집하고, 이 수동 경로는 비교 검증용으로만 남긴다.

## 실행 및 완료 규칙
unit: 계산/기간/스키마; integration: DB/RLS/import/AI mock; e2e: 요구사항→측정→배포→관측→리포트. 실제 스크립트명은 Phase 0에서 확정(예: npm run lint, typecheck, test, build, test:e2e). CI 결과와 브라우저 테스트 증거 제공. 모바일 Safari 실기기 미사용 시 미검증으로 명시. P0 실패 테스트가 있으면 MVP 완료 아님.

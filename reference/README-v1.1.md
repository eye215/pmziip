# PM.zip 개발 인수인계 v1.1

목표: 요구사항을 성과 측정 가능한 개선 과제로 전환하고 배포 전 기준값부터 배포 후 검증까지 연결하는 멀티 프로젝트 PM 워크스페이스.

읽는 순서: AGENTS.md → docs/01-PRD.md → docs/02-FRD.md → docs/03-architecture.md → docs/04-phases.md → docs/05-tests.md. Claude Code는 CLAUDE.md 참조. reference/pmzip.html은 기존 로컬 프로토타입으로 운영 코드가 아니다.

## 첫 실행 지시
저장소를 검사하고 기존 코드/테스트/배포 상태를 파악하라. 신규 저장소라면 Phase 0부터 진행하라. 기존 저장소라면 변경하지 않고 차이를 먼저 기록하라. 한 번에 한 Phase를 구현하고 자동 테스트 및 인수 기준을 통과한 뒤 다음 Phase로 이동한다. 운영 데이터나 외부 서비스 연결은 명시 승인 전 금지. 모든 테스트는 합성 데이터 사용. 실제 AI/DB 연결 없이 완료했다고 보고하지 말 것.

## MVP 완료 기준
하나의 요구사항 원문에서 복수 개선 과제를 생성하고, 각 과제에 측정 계획 및 기준값을 연결하고, 실제 배포일을 기준으로 결과 데이터를 입력하여 월별 및 과제별 검증 리포트를 재현 가능하게 생성한다. 승인되지 않은 AI 추천은 확정 지표가 아니다.

## v1.1 변경점
고객사 계층, 통합 수집함, 월별 조회 기준, 배포 범위/실제 노출/롤백, 차트 마커, 측정 일정, 월별 리포트 마감 및 통합 조회를 P0에 추가했다. 각 문서의 v1.1 절은 기존 내용과 충돌 시 우선한다. 실제 배포/코드 구현은 포함하지 않는다.

# PM.zip 기록 동기화 (Apps Script 웹 앱)

PC와 휴대폰이 같은 기록(원문·과제·측정 계획·확정 보고서·공개 부문 실적)을 보도록,
기록을 **내 구글 드라이브의 비공개 스프레드시트**에 저장하는 별도 Apps Script 프로젝트다.
GA·공시·점유율은 이미 각 시트에서 읽으므로 대상이 아니다.

- 기존 GA 내보내기 프로젝트(coach-ga-export, 웹 앱 '나만')와 **분리**한다. 이 웹 앱은
  '모든 사용자' 접근이라 같은 프로젝트에 두면 GA 다운로드가 공개된다.
- 기록 시트는 공유하지 않는다. 웹 앱이 소유자 권한으로 읽고 쓰며, 토큰(Script
  Properties `PMZIP_SYNC_TOKEN`)이 맞는 요청만 받는다. 토큰은 레포·채팅에 넣지 않는다.
- 덮어쓸 때마다 이전 버전을 20개까지 시트에 남긴다. 두 기기가 동시에 바꾸면 앱이
  덮어쓰지 않고 어느 쪽을 쓸지 묻는다.

## 설정 (한 번)

1. [script.google.com](https://script.google.com) → 새 프로젝트 (회사 구글 계정).
2. `Sync.gs` 내용을 붙여넣고, 프로젝트 설정에서 "appsscript.json 표시"를 켠 뒤
   `appsscript.json`도 이 폴더 내용으로 바꾼다.
3. 편집기에서 `setupSync` 실행 → 권한 허용. 실행 로그에 **토큰**과 기록 시트 주소가 나온다.
4. 배포 → 새 배포 → 유형 "웹 앱" → 실행: 나, 액세스: **모든 사용자** → 배포.
   나온 `https://script.google.com/macros/s/…/exec` 주소를 복사한다.
5. PC의 PM.zip → 설정 → 기기 간 기록 동기화 → 주소와 토큰 입력 → "연결하고 동기화".
6. 휴대폰은 설정 → 다른 기기에서 보기의 링크를 열면 동기화까지 같이 연결된다.

토큰이 새어 나갔다고 생각되면 편집기에서 `rotateSyncToken` 실행 후 각 기기에서 다시 연결한다.
`Sync.gs`를 고치면 배포 → 배포 관리 → 새 버전으로 다시 배포해야 반영된다.

# Pretendard (subset)

`PretendardVariable-KS.woff2` — Pretendard Variable 1.3.9 by Kil Hyung-jin,
SIL Open Font License 1.1 (https://openfontlicense.org). Subset for PM.zip:
Basic Latin, Latin-1, general punctuation, arrows, CJK symbols, Hangul
compatibility jamo and the 2,350 KS X 1001 Hangul syllables. Characters outside
the subset fall back to the system font. Weight axis 45–920 is kept.
